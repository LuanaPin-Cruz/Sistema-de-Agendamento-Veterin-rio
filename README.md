# Sistema de Agendamento Veterinário
Um sistema desenvolvido em Java para organizar os atendimentos de uma clínica veterinária. A aplicação usa menus gráficos para cadastrar e consultar agendamentos, com os dados armazenados em um banco MySQL. Funcionalidades - Agendar consultas para cães e gatos. - Consultar a agenda e verificar os horários disponíveis. - Alterar os dados de um agendamento. - Cancelar uma consulta. - Registrar informações do animal, tutor e sintomas. - Informar o porte do cachorro ou o temperamento do gato. A agenda trabalha com 10 horários, identificados pelos índices de 0 a 9. Tecnologias utilizadas - Java: lógica e organização do programa. - Swing: criação dos menus e janelas. - MySQL: armazenamento dos dados. - SQL: consultas e alterações no banco. - JDBC: comunicação entre o Java e o MySQL. - Maven: gerenciamento do projeto e das dependências. Organização do projeto - Main.java: inicia o programa e chama o menu principal. - MenuPrincipal.java: apresenta as opções e recebe as informações da pessoa usuária. - AgendaDAO.java: executa as operações de consulta, cadastro, alteração e exclusão no banco. - ConexaoBD.java: configura a conexão com o MySQL. - model: contém as classes que representam animais e consultas. - database/petshop.sql: contém o script do banco de dados. Aprendizados Com esse projeto, pratiquei orientação a objetos, incluindo herança e polimorfismo, além de aprender mais sobre conexão com banco de dados, comandos SQL e organização de código em classes. Também tive a oportunidade de investigar erros e entender melhor como as partes da aplicação se comunicam.
